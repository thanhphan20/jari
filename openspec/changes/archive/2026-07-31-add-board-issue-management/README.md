# add-board-issue-management

Phase 3a: turn the read-only board into a usable issue tracker — drag issues between columns, open and edit them, create and delete them, filter the board, and see the project they belong to.

Frontend only. Every feature here is built on endpoints the backend already exposes; nothing in `jari-*-service` changes. Modelled on the feature set of [oldboyxx/jira_clone](https://github.com/oldboyxx/jira_clone) (MIT), reimplemented against this project's own API rather than ported.
